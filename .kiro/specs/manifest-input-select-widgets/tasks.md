  - 完了条件: 設計の検証規則 V1〜V8 の受理・拒否をすべて網羅する単体テストと既存のスキーマテストが緑になる

  - ホールド開始時にウィジェット種別へ応じた猶予(入力欄は長時間、既存の連続系ウィジェットは従来どおりの短時間)を設定し、入力欄は編集イベントごとに開始時刻を更新できるようにする

  - 完了条件: 入力欄と既存ウィジェットのホールドが各自の猶予で解除されることを検証する単体テストが緑になり、既存のホールド関連テストも新経路で緑になる
  - _Requirements: 3.1, 3.3_
  - _Boundary: ValueChannel, SurfaceState_

- [x] 4.2 ページ単位の期限管理を撤去し切断時のホールド解放を追加する

  - 完了条件: 切断相当の解放でホールドが残らないこと、ページ側に期限管理が残っていないことを検証するテストが緑になる

- [ ] 5. input ウィジェットの描画・確定送信・編集保護
- [x] 5.1 input エントリを編集可能な入力欄として描画し確定時のみ送信する
  - 文字列型は文字列入力欄、整数・小数型は数値入力欄として描画し、既存のフォールバック分岐へ落ちない位置に構築分岐を追加する
  - 表示専用への降格判定を、値型のみの判定からウィジェット種別を考慮する判定へ変更する(既存 5 ウィジェットに文字列型を割り当てた場合の表示専用降格は従来どおり維持する)
  - 送信は確定イベント(Enter キー押下とフォーカス喪失)のハンドラだけから行い、値変更イベントからは送信しない構造にする。送信は離散系の即時送信経路を使い、型タグはエントリの値型に従って付与する
  - マニフェスト採用時の初期値反映はプログラム的設定として扱い、その反映で送信が発生しないようにする
  - 完了条件: 入力欄が描画され、キーストロークでは送信されず Enter とフォーカス喪失で 1 回だけ値型どおりの型タグで送信されることをロジックテストで確認できる
  - _Requirements: 2.1, 2.2, 2.3, 2.4, 2.5, 2.8_

- [x] 5.2 確定拒否時のエラー表示と拒否後の表示復元を実装する
  - 確定時検証で拒否された値は送信せず、入力欄にフィールドレベルのエラー表示を出す(値域外・範囲外・書式不一致のいずれも自動補正しない)
  - Enter による拒否は編集継続とみなしてエラー表示と保護を維持し、次の有効な確定で解消する
  - フォーカス喪失による拒否では、入力欄の値を当該アドレスの現在値へ復元してエラー表示を消し、送信しなかった旨を一時通知として表示する。エコーバック任せの解消は行わない
  - 表示の強制再適用の口(改訂番号の差分比較を迂回して次回同期で再適用させる経路)を用意し、復元と将来の同種ケースで使えるようにする
  - 完了条件: 拒否時に送信が発生しないこと、フォーカス喪失時に現在値へ復元されエラー表示が消えることをテストで確認できる
  - _Requirements: 2.6, 2.7, 2.9_

- [x] 5.3 編集中の上書き保護を入力欄のイベントへ結線する
  - フォーカス取得とプログラム的設定を除く値変更で保護を開始し、フォーカス喪失および Enter での確定成功で保護を終了する。編集イベントのたびにホールドの期限起点を更新する
  - 保護中は受信値で入力欄の表示を上書きせず、保護解除後の受信値で表示を確定する。送信直後の未エコーバック期間に古い値へ戻らないことを既存の連続系ウィジェットと同等の水準で満たす
  - Enter 確定後に再び打鍵した場合は保護を再開する
  - 完了条件: 保護中のエコーバックが表示を変えず、保護解除後のエコーバックで表示が確定することをロジックテストで確認できる
  - _Requirements: 3.1, 3.2, 3.3_

- [ ] 6. select ウィジェットの描画・送信・選択肢外値の表示
- [x] 6.1 select エントリをドロップダウンとして描画し選択肢を表示する

  - 解決後の選択肢が空のときはドロップダウンを操作不可にして「選択肢なし」の注記を表示し、ダミー項目は挿入しない
  - 入力欄と同一のウィジェット構築分岐を触るため、タスク 5 と並行実行しない
  - 完了条件: インライン・共有参照の双方のエントリで選択肢が表示され、空選択肢のエントリがグレーアウトと注記付きで描画される
  - _Requirements: 4.1, 4.2, 4.3, 4.4_

- [x] 6.2 選択の即時送信とエコーバック確定・選択肢外値の表示を実装する
  - 選択操作(プログラム的設定を除く値変更)で選択文字列を文字列型タグで即時送信する。離散系の既存送信経路を使い、ホールドは使わない
  - 受信値が選択肢内なら通常の選択表示として確定し、選択肢外なら選択を空にしたうえで表示部に受信値をそのまま出す(選択肢一覧には加えない)。選択肢内へ戻ったら表示上書きを解除する
  - 初期値の反映は既存の初期値投入経路を通し、送信を発生させない。初期値が選択肢外でもマニフェストは不採用にしない
  - 表示部の上書きに埋め込む文字列は引用符・改行を安全に扱う。期待どおり動作しない場合は選択肢一覧へ混ぜず、受信値をドロップダウン直下に併記する退避策を採る
  - 完了条件: 選択で 1 回送信されること、選択肢外のエコーバックで選択が変わらず受信値が表示されることをテストで確認できる
  - _Requirements: 5.1, 5.2, 5.3, 5.4, 5.5_
